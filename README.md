# Tasneem - Android RecyclerView Assignment

This is a complete Android Studio project for the RecyclerView assignment.

## Implemented
- RecyclerView for displaying a collection of products.
- GridLayoutManager with 2 columns, matching the two-column product-grid interpretation of the supplied assignment reference.
- Product model class.
- RecyclerView Adapter and ViewHolder.
- Separate XML layouts for the screen and each product card.

## Open the project
1. Extract `Tasneem_Android_RecyclerView.zip`.
2. Open Android Studio.
3. Select **Open** and choose the extracted `Tasneem_Android_RecyclerView` folder.
4. Wait for Gradle Sync to finish. Internet access is needed the first time to download Android Gradle Plugin and dependencies.
5. Run the app on an emulator or Android phone.
6. Take screenshots from the running app for the assignment submission.

## GitHub submission
Create a new public GitHub repository, upload the contents of this project folder (not the ZIP itself), then submit the repository URL.

## Important
The product illustrations are emoji placeholders, not photographs. This project implements the product-grid structure described for the reference design. Compare it with the instructor's attached reference image before final submission if exact images, labels, or spacing are required.
